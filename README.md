# SNHU.CS.499
ePortfolio to showcase skillsets

Enhancing my skillsets related to transitioning and storing a dataset from an existing source, moving and processing that data through different systems, and ultimately connecting it to a UI is a major focus of my ePortfolio. I want to show that I understand how the different parts of a system connect, including the data, database, backend, algorithms, and user interface. I also want to connect what I have learned in Computer Science to my current work experience with ERP systems, cloud infrastructure, and cloud data storage. My goal is to show that I can take existing information, work with it in different systems, and turn it into something that can be used and understood by an end user.

For Software Engineering and Design, I selected my CS-305 REST Service project. This project gave me experience working with Java and Spring Boot and understanding how a backend service communicates through REST endpoints. I plan to improve the project by adding stronger input validation, centralized exception handling, better endpoint responses, unit testing, and documentation of how the application is structured. I want the finished project to be more reliable and easier to understand and maintain. The main skills I want to show are software design, testing, problem solving, and security. My planned pseudocode shows the basic process of receiving a request, validating the information, processing the request, handling errors, and returning the appropriate response.

For Algorithms and Data Structures, I selected my CS-300 Binary Search Tree project. This project uses a binary search tree to organize and search information from the eBid monthly sales dataset. I plan to improve the project by looking more closely at the efficiency of the search and insertion processes, documenting the Big-O complexity, and comparing the binary search tree approach with a hash table using the same type of data. I think this will help show that I understand why one approach may be better than another depending on the type of data and what the application needs. The pseudocode for this enhancement shows how the dataset is loaded into the tree and how a search moves through the nodes until the value is found or there are no more nodes to search.

For Databases, I selected my CS-340 Animal Shelter CRUD project. This project uses Python and MongoDB to store and retrieve information from an animal shelter dataset. I plan to improve the project by adding better input validation and error handling, improving the database connection process, using MongoDB aggregation operations, and expanding the reporting and dashboard capabilities. I want this project to show how I can take a dataset from an existing source, store it in a database, retrieve and process the information, and then make that information available through a user interface. I also want to demonstrate that I understand the differences and trade-offs between using a NoSQL database and a relational database. The pseudocode shows the process from the user's request, through validation and the MongoDB query or aggregation, to processing and displaying the results.

For my code review, I want to show that I can look at existing code and recognize where it can be improved instead of simply creating something from scratch. I want to focus on areas such as efficiency, functionality, security, testing, and maintainability. In my narratives, I will explain the changes I make and why I chose those changes. I also want to show how I think through technical decisions and how different solutions can affect the overall system. My professional self-assessment will connect these technical skills to my experience as a Scrum Master and Project Manager working with ERP systems, data, and cloud infrastructure.

My ePortfolio intends to showcase how data can move through a complete system, from an existing source or database, through backend processing and algorithms, and eventually into something a user can interact with. I also want the projects to show that I can look at an existing solution, identify areas that need improvement, and make changes based on how the system is actually being used. I still have areas I want to continue developing, especially with AI and some of the more advanced cloud technologies. I would like feedback on whether there are any areas of my projects that would be worth strengthening or any skills that are not coming through clearly enough in the work.
